# piyushmittal.in

Personal brand website for **Piyush Mittal — Business Growth + AI Solutions**.

Static, zero-dependency site: plain HTML/CSS/JS generated by a small Node script. No framework, no build tooling to maintain, so it loads fast and gets strong Core Web Vitals scores.

## Structure

```
src/
  config.mjs     ← name, email, location, social profiles, form endpoint (edit this first)
  content.mjs    ← all copy: 7 services, case studies, blog posts
  build.mjs      ← templates + SEO (meta, Open Graph, JSON-LD, sitemap, robots, RSS)
  static/        ← copied as-is: CSS, JS, favicon, og-image, touch icon
dist/            ← generated site (this is what you deploy)
```

Pages: Home, Services (index + 7 service pages), Work (index + case studies), About, Insights (index + articles + RSS), Contact, 404.

## Build & preview

```bash
node src/build.mjs
```

```bash
npx serve dist
```

## Before launch: fill in the TODOs

Search the code for `TODO`. The important ones:

1. **`config.mjs` → `profiles`**: add your real LinkedIn, GitHub, X, Instagram and similar URLs. They become `sameAs` in the Person schema and "Elsewhere" links in the footer. This is the strongest signal for the "Piyush Mittal" search. Add only profiles that are actually yours.
2. **`config.mjs` → `email`, `location`, `calendarUrl`, `formEndpoint`**. Without a form endpoint, the contact form opens the visitor's email app. A free [Formspree](https://formspree.io) endpoint makes it submit in place.
3. **Headshot**: add `src/static/assets/piyush-mittal.jpg` (square, at least 800px) and point `person.image` in `build.mjs` at it. You can also swap the "PM" portrait blocks for the photo. A real photo matters for trust and for Google's knowledge panel.
4. **Case studies** (`content.mjs → work`): check the scope wording for Tripzivo and Gobind Coach Builders and add real, measurable results.
5. **About page story** (`build.mjs`, About section): add your real background. Specific personal details build trust and help Google tell you apart from other people named Piyush Mittal.

## Deploy

Any static host works. **Cloudflare Pages**, **Netlify** and **Vercel** are all free for this:
build command `node src/build.mjs`, output directory `dist`. Point `www.piyushmittal.in` at the host, and redirect the bare domain `piyushmittal.in` → `https://www.piyushmittal.in` so there's one canonical URL.

## Ranking for "Piyush Mittal": the playbook

The site is technically ready: unique titles that lead with your name, canonical URLs, Person + WebSite + ProfilePage schema linked by `@id`, Service/BlogPosting/Breadcrumb schema, sitemap, robots.txt and RSS. The rest happens off-site:

1. **Google Search Console**: verify the domain, submit `https://www.piyushmittal.in/sitemap.xml`, and request indexing for the home and About pages.
2. **Use one name everywhere**: "Piyush Mittal", with the same photo and the same one-line headline ("Business Growth + AI Solutions") on every profile.
3. **Link both ways**: every profile links to `https://www.piyushmittal.in`, and the site links back through `profiles`. Two-way links are how Google ties the entity together.
4. **Claim the obvious profiles**: LinkedIn (custom URL `/in/piyushmittal…`), GitHub, X, Medium/Substack, Crunchbase, Google Business Profile if you serve local clients, plus any industry directories.
5. **Publish regularly**: one article a month in `content.mjs → posts`, also shared on LinkedIn. Fresh, authored content keeps the site ranking and builds topical authority.
6. **Earn mentions**: guest posts, podcasts, client sites crediting "Website by Piyush Mittal" with a link, and local business features. Each one reinforces the name.
7. **Get reviews and testimonials** from clients. Add them to the site once they're real.

Because "Piyush Mittal" is a shared name, expect page one to take a few weeks to a few months of consistent signals. The steps above are what move it.
